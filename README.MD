# Detalles del proyecto
1. Se tiene esta estructura de la página de inicio en la cual daremos a conocer información del taekwondo potosino.
2. Se creó un menú de navegación donde habrán distintas secciones y en ellas usamos los div, clases y enlaces con la etiqueta `<a>` para movernos entre las páginas.
3. Para el menú en celulares usamos un `input` tipo checkbox oculto junto con un `label` para que se pueda abrir y cerrar sin necesidad de usar JavaScript.
4. En la portada principal usamos etiquetas `section`, `h1`, `p` y un botón estilizado con clases para darle el diseño oscuro con una imagen de fondo y un degradado encima.
5. Se creó la página de institución y la de modalidades usando la misma barra de navegación, pero cambiando el fondo a claro con una clase en el `body` y organizando la información con etiquetas `article` y listas `ul` y `li`.
6. En la hoja de estilos `style.css` usamos variables en `:root` para guardar los colores principales de la página y no tener que repetirlos a cada rato.
7. También aplicamos `display: flex` y `display: grid` para acomodar las tarjetas, el logo y los textos en columnas de forma ordenada.
8. Por último agregamos `@media` para que la página sea adaptable y se vea bien tanto en pantallas grandes de computadora como en celulares.
9. Se desarrolló la página de galería usando las etiquetas <video> y <source> para reproducir videos locales de entrenamientos con portada (poster), además de tarjetas con <figure>, <figcaption> y etiquetas flotantes para destacar las competencias.
10. Por último agregamos @media (a 900px para tablet y 600px para celular) para que toda la página sea adaptable y se vea bien tanto en pantallas grandes de computadora como en dispositivos móviles.
